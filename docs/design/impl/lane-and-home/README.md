# The returns lane, Home, and Now playing — rendered

Frames from the **real binary**, headless, on a private Xvfb with all six XDG
redirections from `docs/DEVELOPMENT.md`. Nothing touched the owner's session;
every run logged

```
[mpris] no session bus; desktop media controls unavailable (…)
```

which is the receipt that the isolation held. Rebuild them with:

```sh
toolbox run -c baz-dev env CARGO_TARGET_DIR=target/tb \
  cargo build --release -p baz --features device-output
toolbox run -c baz-dev docs/design/composition/tools/mkfixture.sh /tmp/baz-lane-fix
toolbox run -c baz-dev env FIX=/tmp/baz-lane-fix \
  docs/design/impl/lane-and-home/capture.sh
```

The fixture is 25 albums / 206 tracks of silent FLAC with generated covers, and
three playlists written at three different mtimes so the lane's *last touched
first* order is visible rather than asserted.

## What the collapse does to the grid

Generated by `columns.py`, which is `Grid::new`'s own arithmetic
(`crates/baz/src/shelf.rs`) at `Balanced` over `window − sidebar −
INDEX_LANE_W − WALL_SCROLLBAR_W` — exactly `Shelf::grid_width`. Printed at the
end of every capture run, so this table cannot drift from the code.

```
| Window | Lane                 | Grid width | Columns |    Art | Gutter | Margin |
|--------|----------------------|------------|---------|--------|--------|--------|
|   1280 | no lane (before)     |       1168 |       4 |    242 |     40 |     40 |
|   1280 | expanded, 280        |        888 |       3 |    243 |     40 |     40 |
|   1280 | collapsed, 96        |       1072 |       3 |    304 |     40 |     40 |
|   1440 | no lane (before)     |       1328 |       4 |    282 |     40 |     40 |
|   1440 | expanded, 280        |       1048 |       3 |    296 |     40 |     40 |
|   1440 | collapsed, 96        |       1232 |       4 |    258 |     40 |     40 |
|   1920 | no lane (before)     |       1808 |       6 |    255 |     40 |     40 |
|   1920 | expanded, 280        |       1528 |       5 |    258 |     40 |     40 |
|   1920 | collapsed, 96        |       1712 |       5 |    294 |     40 |     40 |
```

Three things worth reading off it:

1. **At two of the three widths the collapse does not change the column count
   at all — the covers just get bigger** (1280: 243 → 304, +25 %; 1920:
   258 → 294, +14 %). That is the best possible version of this gesture: it
   reads as *zoom*, not as reflow, which is also what it means.
2. **At 1440 the count does change** (3 ↔ 4), because the wanted count and the
   `ART_MIN` ceiling land either side of the boundary there. It is unavoidable
   — any width delta crosses a column boundary at *some* window size — and it
   is why the answer is the structural one about which press may re-hang rather
   than a choice of widths.
3. **The margin is 40 in every row**, so the nearest cover is never closer than
   `HANG` to the lane, at any width, in either state. That is why the lane
   needs no drawn seam beyond its own hairline.

### Home

| Frame | What it shows |
|---|---|
| `07-home-without-an-interrupted-run-1280` | No snapshot yet: `CONTINUE` is **absent, not empty**, and `RECENTLY ADDED` carries the page alone. |
| `16-home-with-an-interrupted-run-1280` | The same baz, reopened. The placard: `ANNE-MARIE PUIG` in letterspaced caps, ***Ochre*** in serif italic, `1999 · FLAC · 16-bit · 44.1 kHz`, **the needle at exactly the sleeve's width** with the tick at the position, and `Resume · Anhydrous 11 · 3:12 of 4:34`. Nothing is drawn on the artwork. |

The capture prints `session.toml` after the quit, so the snapshot is visible
as a file rather than only as a rendering.

**One thing is seeded, and it is a limit of the harness rather than of the
feature.** Two things write the snapshot: the run moving (a track boundary),
and the exit — the only writer of the *elapsed* milliseconds. Under Xvfb with
no window manager, `xdotool windowclose` races winit's own X11 teardown and the
process dies in `GetGeometry` before the update loop sees the close request, so
the position on disk is the track boundary's zero. The exit path itself is one
function (`App::leave_for_good`) reached by both exit routes; what cannot be
shown headlessly is a compositor delivering the request. The script therefore
writes `position_ms` in, to render a needle that is partway rather than a
needle at zero. The needle's arithmetic is pinned by tests
(`the_needle_is_the_sleeves_measure_at_every_position` and its two neighbours),
not by this frame.

### The panel — the affordance, and the ghost

The owner: *"a more clear indicator that something is a click area… as in a
highlight of some sort on the playlist items… right now it's a bit…
unresponsive"*. The cause was not a missing style — the rows already asked for
`theme::track_row` — but that its hover was the **constant** `plinth`, and the
panel's own ground *is* `plinth`. The rows painted the colour already under
them. The same bug was in the context menu's items.

| Frame | What it shows |
|---|---|
| `09-panel-at-rest-1280` | Every row at rest, the ghost at the head of the list. |
| `10-panel-ghost-hovered-1280` | The ghost answering the pointer — the whole row, the whole hit area. |
| `11-panel-row-hovered-1280` | A real list answering it exactly the same way. |
| `12-ghost-in-entry-1280` | Pressed: the label is a field in place, the caret already in it, `Save` inert while empty. |
| `13-ghost-named-save-live-1280` | A name typed: `Save` acts. |
| `14-ghost-refused-1280` | A taken name — **refused before the press**, in the storage layer's own words, with `Save` inert. |
| `15-ghost-saved-and-returned-1280` | Saved: the list is real, and a fresh ghost is back at the head. |

## What is not here

- **A before/after pair of the mute hover.** The "before" is a frame of a row
  that looks identical at rest and under the pointer, which is a picture of
  nothing; `09`/`10`/`11` show the fixed behaviour, and
  `a_row_answers_the_pointer_on_every_ground_it_stands_on` is what actually
  holds it — it asserts over all four surface planes in both rooms that a
  hover never paints the ground back onto itself, which no screenshot can.
- **The light room.** Every frame is `BAZ_ROOM=closing-time`. The contrast
  floors and the ladder's rise are asserted for both rooms in `theme.rs`.
